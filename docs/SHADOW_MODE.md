# Shadow Mode

Shadow mode is the Phase 1 operating target. The bot may discover, crawl, extract and compose real supplier candidates into `shadow_profiles`, but it cannot publish them to EventFlow.

A shadow profile is the reviewable contract EventFlow integration will later consume: business identity, category/location, website, generated description, public contact facts, advertised prices, services/packages, evidence references, confidence and quality scores.

This gives the project a hard acceptance boundary: we can prove supplier quality and autonomy before any production EventFlow write path exists.
