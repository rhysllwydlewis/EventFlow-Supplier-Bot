# Phase 3 acceptance evidence

For the final Phase 3 sign-off, capture the following from the production Control Centre or `npm run phase3:report`:

- run id and start/completion timestamps;
- candidate count (minimum 100, maximum observed before drain 250);
- Shadow profile count and yield;
- average publication quality and data confidence;
- evidence, email, phone, advertised-price and package coverage;
- distinct, probable-duplicate and strong-duplicate counts;
- quarantined/rejected counts;
- publication-eligible, review, blocked and SEO-ready counts;
- total estimated AI cost and cost per candidate;
- proof that Shadow mode stayed active and Publishing, Claim notices, Marketing and SEO indexing stayed off for the run.

If the report exposes a systematic failure pattern, tune the relevant extractor/dedupe/compliance logic and repeat enough affected samples to show that the defect is corrected before proceeding to Phase 4.
